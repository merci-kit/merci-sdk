Lesson 36: Telemetry: the same run, as an OTLP envelope on disk

the OTLP envelope, the gen_ai span tree, redaction, batching

1. Why This Feature Exists

One real model turn runs through .withTelemetry({ exporter }). The exporter is not mocked: it builds the OTLP/JSON body itself and POSTs it to a collector that writes every envelope to scratchpad/examples/22-telemetry/. The file is then read back and parsed — the proof is the bytes on disk.

2. What the Example Demonstrates

A — the span tree
the run exports invoke_agent with one CLIENT chat {model} span under it (the ApiObserver seam), gen_ai attributes and a duration, and the whole envelope is a file we can read.
B — the attribute rules: otelAttribute encodes a string / int
the attribute rules: otelAttribute encodes a string / int / double / bool, drops a non-scalar, and caps a long string.
C — what never leaves
the prompt, the answer and a leaked key are not in the file; only allowlisted scalar fields become attributes.
D — batching
batchSize posts on the fill, flushIntervalMs posts on the timer — no explicit flush() needed.
E — observer composal
CompositeApiObserver delivers the same call to an EventEmitterApiObserver (the app's own bus) AND to the exporter, so the app's events and the trace are one source, not two code paths. Public API: createOtlpExporter, otelAttribute, CompositeApiObserver, EventEmitterApiObserver, withTelemetry, EVENTS. /**
 * A collector that writes each OTLP/JSON envelope as one line of a file — the
 * exporter's real HTTP contract, with the bytes kept for inspection.
 * @param {{file: string}} arg0
 * @returns {{posts: Array<{url: string, raw: string, headers: Record<string, string>}>, fetch: (url: string, init: any) => Promise<{ok: boolean, status: number}>}}
 */
function fileCollector({ file }) {
    /** @type {Array<{url: string, raw: string, headers: Record<string, string>}>} */
    const posts = [];
    /** @param {string} url @param {any} init */
    const fetch = async (url, init) => {
        const raw = String(init?.body ?? '');
        posts.push({ url: String(url), raw, headers: init?.headers ?? {} });
        await mkdir(OUT_DIR, { recursive: true });
        await appendFile(file, `${raw}\n`, 'utf8');
        return { ok: true, status: 200 };
    };
    return { posts, fetch };
}
