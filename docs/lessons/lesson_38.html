Lesson 38: merci behind an editor protocol

the ACP v1 agent: session lifecycle, updates, the fail-closed permission model

1. Why This Feature Exists

An editor speaks the Agent Client Protocol to this process. The ACP client is the official SDK client on the other end of a real NDJSON transport (two byte pipes, in memory); the ACP agent is createAcpAgent wrapping a live merci session scoped to a workspace.

2. What the Example Demonstrates

A — the editor connects
initialize negotiates ACP v1 and reports ACP_AGENT_VERSION; the client announces its capabilities.
B — session/new
the agent mints a session id and the merci session factory receives the editor's cwd; session/list shows it.
C — a coding question
a real model reads config.json in the workspace and answers with the retry limit; every thought, message chunk and tool call arrives as a session/update notification over the transport, and the turn ends with ACP_STOP_REASONS.END_TURN.
D — permissions
permissionAllowed grants only an option the agent offered — a reject, an unknown option id, a cancelled outcome and an empty list all deny. Then a live shell command is offered to the editor, the editor rejects it, and the command never runs.
E — cancellation
session/cancel is a notification, sent while the turn is streaming; the prompt resolves with the CANCELLED stop reason. What this shows: - the ACP v1 agent and session lifecycle, driven by a real client - fail-closed permissions wired from a shell gate to the editor - stop reasons as the protocol's answer for every turn Run: node examples/27_acp_agent.mjs Needs: PROVIDER + provider credentials in secret.env. @version 0.25.0

/**
 * Two byte pipes wired into a pair of NDJSON streams: the agent writes one way,
 * the client writes the other. Real protocol bytes, no child process.
 */
function ndjsonDuplex() {
    const clientToAgent = new TransformStream();
    const agentToClient = new TransformStream();
    return {
        agentStream: ndJsonStream(agentToClient.writable, clientToAgent.readable),
        clientStream: ndJsonStream(clientToAgent.writable, agentToClient.readable),
    };
}
