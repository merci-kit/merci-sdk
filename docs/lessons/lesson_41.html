Lesson 41: One call: policy + scheduler + workspace + operator

one createOrchestration call binding policy, scheduler, workspace and operator; the spend ledger

1. Why This Feature Exists

The primitives have their own examples; this one is the composition root. A repository-owned WORKFLOW.md says how work runs, a three-item board says what work exists, and one createOrchestration call binds the two to a policy, a scheduler, a workspace manager and an operator surface:

2. What the Example Demonstrates

A — one call
policy.snapshot() is started and healthy, the scheduler took its interval, active/terminal states and concurrency from the file, and the workspace manager, ring and HTTP handler exist.
B — two items
start() dispatches both Todo items under the file's cap of 2, each in its own workspace directory, and the third item stays in Backlog because the board says it is not active work.
C — the operator
GET /api/v1/state is the live counts and totals, /api/v1/items/<id> is one item (status parked — the documented end of a completed attempt when continuations are off), / is the formatStatus page, and POST /api/v1/refresh moves the tick count.
D — the ring
createEventRing keeps the projected history. The default DEFAULT_PREFIXES omit session records; passing prefixes: [...DEFAULT_PREFIXES, 'session:'] opts them in. A host mount of createOperatorHttpHandler reads the same system, and its item feed stays item-scoped: a record without an identifier cannot belong to it.
E — the spend
one DAG attempt hands planFor a cap-less ledger. The hook's own session, the engine's objective restatement and the step all fold into totals; a call through the client the host kept stays out. What this shows: - the file owns interval, states, concurrency and the workspace root - the model is passed by the host and never read from the contract - one attempt's spend is a ledger, not an estimate; budget bounds a unit - the operator reports the same snapshot the host can read Run: node examples/31_orchestration.mjs Needs: provider credentials in secret.env (PROVIDER=google_genai). @version 0.25.0
