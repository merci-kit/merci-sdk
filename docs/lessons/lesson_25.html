Lesson 25: Subagents in Action: 4 Engines Compared

Benchmark the same objective and subagent profiles across FOUR orchestration engines: Naive Session, DAG Workflow, StateMachine, and MAA, plus background detached subagents.

1. Why This Feature Exists

Choosing the right orchestrator is critical. Running the exact same objective and profiles through all four architectures demonstrates the unique strengths, token efficiencies, and error resilience of each approach.

2. Key Symbols and Exports

Engine A: Naive Session
Single agentic loop with task tool delegation.
Engine B: DAG Workflow
Topological task execution where each node calls specialist subagents.
Engine C: State Machine
Cyclical node graph where terminal states are verified with retries.
Engine D: MAA
Structured runTasks + planForEach + judge aggregation.
background: true
Detached subagent execution with asynchronous task:finish notification.
