Merci SDK API Reference

The TypeScript surface of Merci SDK v0.26.0, grouped by task. Signatures below use the SDK's single-object argument convention. The full generated export table (§8) is authoritative; §§1–7 explain the calls you actually make.

1. Client Lifecycle and Bootstrap

Core Factory Functions

import {
    ProviderType,

    loadCredentials,

    getToolModel,
    getEmbeddingModel,
    getEmbeddingDimensions,
    getAvailableModels
} from 'merci-sdk';
resolveProvider({ provider }): string
Resolves the active provider from environment variable PROVIDER (renamed from BACKEND), or returns the argument.
initializeClient({ provider, options }): Promise<{ client }>
Initializes the unified transport client for the selected provider.
getDefaultModel({ provider }): string
Returns the primary orchestrator/planner model ID for the given provider.
getToolModel({ provider }): string
Returns the cheap leaf-subagent model ID. Throws ConfigurationError on an unknown provider. See examples/15_delegation.mjs.
getEmbeddingModel({ provider }): string
Returns the embedding model ID for the given provider from DEFAULT_<PROVIDER>_EMBEDDING_MODEL (falling back to DEFAULT_GEMINI_EMBEDDING_MODEL / DEFAULT_EMBEDDING_MODEL). Used by client.embed() and the memory vector tier. Resolves to '' for providers whose embeddings are model-less.
getEmbeddingDimensions({ provider }): number
Returns the embedding output dimensionality for providers that require one from DEFAULT_JAI_EMBEDDING_DIMENSIONS (default 1024); 0 for providers where it does not apply.
getAvailableModels({ client, provider }): Promise<{ id, name }[]>
Backend profiles or models the client can address. Used by the quickstart to list what is reachable. See examples/01_quickstart.mjs.

2. ChatSession and SessionBuilder

Session Configuration Methods

const session = client.session(model)
    .withSystemMessage(str)
    .withProtocol('responses') // e.g. 'responses' on an OpenAI-compatible endpoint; provider-gated
    .withParameters({ temperature, maxTokens, reasoningEffort }) // or b => b.asJson().withSchema(jsonSchema)
    .withTools([tool1, tool2])
    .withMemory(memoryProvider)
    .withTodos(todoStore)
    .withObjective(str);
session.step({ messages, options }): AsyncGenerator<StepEvent, StepFinalState>
One turn over messages (replace history with finalState.messages; never push duplicates). Yields text / thought / tool_call_delta / quota / citations / error; throws MaxTurnsExceededError when the tool budget is spent. See examples/01_quickstart.mjs, 02_conversation.mjs.
session.run({ initialInput, options }): Promise<string>
Agentic loop to a terminal answer: tools, staged follow-ups, abort, streamed-input and token/money budgets. initialInput is text or an async iterable (one user turn per chunk). See examples/07_agent_loop.mjs.
session.getLastRun(): { text, messages, usage, citations, sources }
The last completed run in one object: the deliverable run() returned, the final message rows, and the usage/citations/sources the RUN_END event carries. Empty before a run and after a failed one. See examples/07_agent_loop.mjs.

4. Budget, Guardrails, Permissions and Telemetry

Policy & Budget

import {
    createGuardrails,
    isToolPermitted
} from 'merci-sdk';

client.session(model)
    .withBudget({ budget: { maxTotalTokens: 200_000 } })
    .withGuardrails({ rules: [{ name: 'no-secrets', phase: 'input', pattern: /AKIA[0-9A-Z]{16}/ }] })
    .withPermissions({ allow: ['read_*'], deny: ['write_*'], mode: 'acceptEdits' })
    .withTelemetry({ exporter });
withBudget({ budget: { maxTotalTokens, maxBudgetUsd } })
Caps what one run may spend. The token cap always works. The USD cap is enforced against the amount the provider reports — the SDK never estimates a price and ships no price table; a provider that reports no amount emits run:budget_unreported and the run continues on the token cap.
withGuardrails({ rules })
The tripwire on what enters (phase: 'input') and leaves (phase: 'output') the model. action: 'block' refuses the run with a GuardrailViolationError; action: 'warn' reports and continues.
withPermissions({ allow, deny, mode })
Decides which tools the model may call (tool names or globs such as read_*; an argument pattern like Bash(rm:*) throws ConfigurationError) and how a gated tool is treated: default asks every time, acceptEdits approves only a tool branded editsFiles: true (and never one that also declares runsCode) — the SDK's save_artifact, or a host tool that sets the flag on its definition; a tool loaded from an MCP server never carries it — bypassPermissions approves everything.
createOtlpExporter(options)
Exports a run as an OpenTelemetry gen_ai span tree to an OTLP/HTTP endpoint: invoke_agent per run, chat {model} per vendor call (with gen_ai.usage.*), execute_tool {name} per tool call; every other event is a span event. CompositeApiObserver runs it next to the default observer.
withToolTimeout({ ms }) / withHooks({ hooks })
A per-tool deadline keeps one hanging tool from stalling the turn; the request:after hook chain now fires with the round trip.

Deterministic context folding with explicit loss markers — zero silent truncation.

Classified retry policies with abort-aware jittered exponential backoff and a circuit breaker.

7. Observability and Logging

Structured Logging, Events & Streams

import {
    log,
    configureSdkLog,
    attachEventLogger,
    createStreamLogger,
    canonicalEventNames,
    defaultDisplay
} from 'merci-sdk';
log.info / warn / error / fatal / debug / trace / success / thinking / event / check / list / totals / dump / flow / step / section / option / condition
The shared logger singleton (zero logging dependencies). fatal always prints to stderr; dump renders a boxed, redacted JSON block; event prints a summarized canonical event.
log.wire({ kind, meta, full })
LLM wire traffic ('request' | 'response' | 'retry'): a metadata brief by default (→ POST … msgs=3 params=temperature,top_p; contents=N config=… for Gemini; body=Nb for JAI). Full request bodies appear at level: 'trace' or full: true — messages, contents, params, config, and the parsed body. Bodies are always redacted.
log.toolResult({ n, r, full })
Tool output: truncated to one line at info, expanded (redacted) at debug/trace or full: true.
log.child({ …fields }) · log.timer({ label }) · log.isLevelEnabled({ level }) · log.configure({ level, format, colors, extended, quiet, namespaces, correlation, redact, sink, timestamps })
Scoped context (context on every JSON record), elapsed-time timers, threshold queries, and full configuration. Levels: trace < debug < info < warn < error < fatal < silent. Formats: pretty | json (one NDJSON record per line) | auto (pretty on a TTY, NDJSON when piped). Env fallbacks: LOG_LEVEL, LOG_FORMAT, NO_COLOR.
configureSdkLog({ extended, quiet, level, format, colors })
Configures the shared log singleton; level/format also honor LOG_LEVEL/LOG_FORMAT when omitted.
attachEventLogger({ emitter, log, level, filter }) → () => void
Subscribes a registry-driven catch-all to any client/session/orchestrator emitter: every canonical event is logged — summarized, redacted, level-gated — so a newly registered event is visible immediately (no hand-maintained name list). Uses onAny on a MerciEventEmitter. Returns an unsubscribe function.
createStreamLogger({ log, level, ignore }) → (event) => void
Logs the per-step agentic stream (quota, first_token, finish, truncated, compaction, …); text/thought are skipped by default because the display already renders them.
canonicalEventNames() → string[]
Every canonical event name in the EVENTS registry (unique; the bare error name is excluded to preserve Node's throw-on-unhandled semantics).
defaultDisplay({ also, stream })
The default runAgenticLoop display. stream (default 'debug', or false to disable) also attaches createStreamLogger at that level, so -v/LOG_LEVEL=debug turns on the full step stream.
Redaction
Keys matching authorization / apiKey / password / secret / token (exact or suffix, case-insensitive) are masked as [REDACTED] in every log path — pretty, NDJSON, wire bodies, tool args, and dumps.
