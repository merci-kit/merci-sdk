Engineered for Production Agents

Merci SDK eliminates fragmentation across AI providers with clean abstractions, strict security boundaries, and resilient orchestration.

3 Standards × 7 Providers

OpenAI, Anthropic Claude, Google Gemini, Vertex AI, OpenRouter, OpenCode, and Local Stack.

Stateless Resend

History is owned by your application. Every step provides an immutable updated message row (finalState.messages), preventing server-side vendor lock-in.

MCP and A2A Ecosystem

First-class Model Context Protocol client support and Agent-to-Agent JSON-RPC delegation via discoverable agent cards and cross-agent telemetry.

3-Layer Security Gate

Shell tools are strictly partitioned into Safe, Blocked, and HITL-gated commands. Environmental variable inspection prevents accidental secret leaks.

Persistent Memory

Composite and local file memory providers with background distillation, eager preload, recency fallback, and untrusted-fact escaping.

DAG and State Machines

Plan-and-execute workflows, evaluator-driven replan, hierarchical sub-DAGs, StateMachine graphs, and multi-agent discussion swarms.

Context and Compaction

Global objective threading, deterministic foldContext, loss markers, history compaction, and save_artifact persistence by reference.

Enterprise Resilience

Classified retry policies, abort-aware exponential backoff, sliding-window stream timeouts, parameter warnings, and credential redaction.

Agent-Readable by Design

Coding agents get a bundled SKILL.md, full type declarations for every subpath, a generated API reference, and 32 runnable examples — so they build correctly on the first try.

Unattended Orchestration

A repo-owned WORKFLOW.md, per-item workspaces, a work-item scheduler and a read-only operator API — bound by one createOrchestration call, with policy health visible instead of looking idle.
